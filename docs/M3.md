# M3：规则与 AI

> 状态：核心范围已完成 | 开始日期：2026-08-11

## 目标

在 M1 的固定 tick、命令缓冲和确定性基础上，建立“事件 → 规则 → 命令 → 世界演化”的第一条可运行链路，为后续 FSM、状态机、行为树和领域插件提供稳定边界。

## 工程价值

- 让世界状态能够由事件和规则持续演化，而不是把业务流程硬编码进核心循环；
- 保证规则动作只能经命令缓冲提交，支持确定性回放和调试；
- 用事件类型、优先级和规则版本建立可审计的执行顺序；
- 为消防、交通、工业等领域插件提供不修改核心平台的接入点。

## 范围

### M3-A：事件与轻量规则

- 确定性事件总线和未来事件表（FEL）；
- 条件表达式的编译后数据结构和类型安全求值；
- 决策表/规则注册、优先级和版本校验；
- 规则动作生成 `simulation::CommandBuffer` 命令；
- 事件、规则和命令的单元及集成测试。

### M3-B/C 批次

- M3-B：Tier1 FSM、Tier2 轻量分层状态机和有界 AI 任务调度；
- M3-C：BehaviorTree.CPP、Lua、纯 C ABI 动态库插件和版本化 AI 制品工具；
- WASM 运行时在插件边界稳定并完成开销验证后接入。

## 非目标

- 不在 M3-A 实现完整图形化行为树/状态机编辑器；
- 不把规则评估改成 RETE 网络；
- 不让规则或 AI 直接修改世界对象、ECS 或空间索引；
- 不实现客户端协议、WAL/持久化和分布式 authority handoff。

## 依赖

- M1 `foundation`、`world_model`、`simulation`、`schema`；
- M2 空间查询接口作为后续规则预筛选边界；
- M3-C 使用 vcpkg `m3` feature 的 BehaviorTree.CPP、sol2、Lua 和 WasmEdge。

## M3-A 验收标准

- 同 tick 事件按优先级降序、序列号升序确定性处理；
- 事件队列只取出到期事件，未来事件保持顺序；
- 条件表达式支持整数/浮点、布尔和字符串比较；
- 决策表按规则优先级和规则 ID 稳定执行；
- 规则动作只能进入命令缓冲，并在目标 tick 提交；
- 默认构建、vcpkg 构建和全部测试通过。

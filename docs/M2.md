# M2：空间与流式

> 状态：核心范围已完成 | 开始日期：2026-08-11

## 目标

建立 GeoWorld 的全球坐标锚、局部计算坐标和 Cell 空间主轴，为后续空间查询、流式加载、AOI 和分布式分片提供稳定的键与边界语义。

## 有什么用

- 在全球范围保持位置精度，避免经纬度直接进行米制计算；
- 用局部 ENU 坐标承载高频物理和邻域计算；
- 让同一套 Cell 同时服务流式加载、AOI、系统激活和未来分片；
- 使对象跨 Cell 迁移可以产生稳定、可回放的空间事件。

## 范围

1. WGS84 geodetic、ECEF double 和局部 ENU 类型及双精度转换；
2. L0 全球键接口，预留 S2 Cell ID；
3. L1 固定大小、可分层 Cell 网格；
4. Cell 归属、邻居枚举和跨 Cell 迁移事件基础；
5. 动态实体空间哈希索引的接口和最小实现；
6. M2 真实 2.5D 场景测试 fixture 的接口；
7. 多流式源的 Cell 需求合并、预取和生命周期差集规划。

## 非目标

- 不实现完整 GDAL/PostGIS 导入管线；
- 不实现 3D Tiles、quantized-mesh 和 MVT 分发；
- 不实现完整流式异步 I/O、客户端 AOI 协议和分布式 authority handoff；
- 不把 Web Mercator 用于服务端米制计算。

## 主要交付物

- `libs/spatial` 坐标和 Cell 公共 API；
- `libs/spatial` 的 `StreamingPlanner` 和 AOI/SpatialQuery 组合接口；
- 坐标精度、极端纬度和 Cell 边界单元测试；
- 动态对象跨 Cell 的 O(1) 归属更新基线；
- 2.5D AOI 放大倍数 PoC 框架；
- 多源流式需求规划和生命周期差集；
- M2 基准和容量记录。

## 依赖

- M1 `foundation`、`world_model`、`debug`；
- PROJ/S2/Boost.Geometry 由 `m2-spatial` vcpkg feature 提供，GDAL/H3 仍留待后续阶段；
- 当前第一批只使用标准 C++ 数学实现，避免 GIS 依赖阻塞坐标单测。

## 验收标准

- WGS84 geodetic ↔ ECEF 转换在已知控制点误差范围内；
- ECEF 到 ENU 在区域原点附近保持局部坐标精度；
- Cell 边界采用半开区间，边界点归属不抖动；
- 同一坐标和 Cell 配置得到相同层级键；
- 跨 Cell 更新不需要重建全局索引；
- 默认构建、vcpkg 构建和全部测试通过。
